Idealized balloon assumption. This first-pass solver treats the balloon as able to select among atmospheric wind layers; “unlimited” assumes instantaneous altitude changes. It does not model ascent/descent time, balloon drag, payload, terrain, launch constraints, or uncertainty. Stoplight colors show forecast reachability bands, not probabilities of success.
Forecast source. Wind fields are loaded live from the Open-Meteo GFS & RRFS API, which serves NOAA GFS globally and higher-resolution RRFS in North America. Forecasts update as new model runs become available. Always check the latest official forecast before using a scenario.
